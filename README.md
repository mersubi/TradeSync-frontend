# 📦 Архитектура и описание проекта TradeSync (Frontend)

Документ содержит описание архитектуры, структуры каталогов, дизайн-системы, назначения компонентов и структуры клиентской части системы **TradeSync** (автоматизация B2B-закупок шин с ML-сопоставлением прайс-листов и алгоритмом MILP-оптимизации сплита заказов).

## 🎨 Дизайн-система и UI-компоненты

### 1. Цветовая палитра и дизайн-токены (`src/style.css`)
В Tailwind CSS v4 конфигурация задаётся в CSS через директиву `@theme`. Фирменные цвета вынесены в токены `--color-brand-*`:
- **Фон приложения:** `zinc-50` — чистый светлый фон для комфортной работы с большими таблицами данных.
- **Карточки:** `bg-white ring-1 ring-zinc-200/70 shadow-soft rounded-2xl`.
- **Контрастный сайдбар и акценты:** `zinc-950` в сочетании с лаймовым акцентом `brand-400` (`lime-400`) для главных кнопок и активного пункта меню.
- **Типографика:**
  - `Inter` (`--font-sans`) — для основного интерфейса и навигации.
  - `JetBrains Mono` (`--font-mono` + `tabular-nums`) — моноширинный шрифт для числовых данных: цен, артикулов (SKU), процентов и счётчиков.

### 2. Логика «Светофора» (Traffic Light) — `src/utils/confidence.ts`
Расчёт уровня уверенности ML-модели инкапсулирован в чистой функции `getConfidenceLevel(score)`:
| Уровень | Диапазон `score` | Цвет бейджа | Назначение |
| :--- | :--- | :--- | :--- |
| **`high`** | `> 0.85` (> 85%) | 🟢 Лаймовый (`bg-lime-100 text-lime-800`) | Высокая уверенность — автоматическое сопоставление |
| **`medium`** | `0.60 – 0.85` (60–85%) | 🟡 Янтарный (`bg-amber-100 text-amber-800`) | Средняя уверенность — рекомендуется проверка оператором |
| **`low`** | `< 0.60` (< 60%) | 🔴 Коралловый (`bg-rose-100 text-rose-700`) | Низкая уверенность — требуется ручной выбор номенклатуры |

### 3. Сквозной бизнес-процесс
Компонент `ProcessStepper.vue` визуализирует 4 ключевых этапа закупки:
1. **Загрузка прайса (`/upload`)** → передача файла `.xlsx/.csv` через `POST /api/v1/procurement/upload` и отслеживание фонового прогресса через WebSocket `/api/v1/ws/procurement/{session_id}`.
2. **ML-валидация (`/validation`)** → фильтрация по светофорной индикации, ручная перепривязка позиций (`PATCH /api/v1/procurement/items/{item_id}`, Active Learning) и утверждение сессии (`POST /approve`).
3. **Матрица и сплит (`/matrix`)** → сопоставительная таблица цен поставщиков с выделением лучших предложений и запуск алгоритма оптимизации MILP (`POST /optimize`).
4. **Экспорт в 1С (`/matrix`)** → формирование и выгрузка спецификации заказа в формате **1С CommerceML 2.08 XML** (`GET /export/1c?format=xml`), Excel или JSON.

## 📋 Навигация по ключевым техническим модулям

### 1. `src/api/client.ts`, `src/api/auth.ts` и `src/api/procurement.ts`
- **`client.ts`**: настройка инстанса Axios. Request-интерцептор автоматически подставляет JWT-токен (`Authorization: Bearer <token>`), а Response-интерцептор обрабатывает ошибки `401 Unauthorized`, сбрасывает локальное хранилище и генерирует событие `tradesync:unauthorized`.
- **`procurement.ts`**: типизированные клиентские методы для взаимодействия с бэкендом (управление поставщиками, сессиями, загрузка файлов через `FormData`, рематчинг, расчёт сплита и получение файлов выгрузки).

### 2. `src/store/authStore.ts`
Хранилище Pinia на базе Composition API (`defineStore`). Управляет состоянием авторизации, хранит данные пользователя и токен, декодирует payload JWT (`sub`, `role`) и предоставляет метод `hasRole()` для проверки прав доступа в навигационных гардах роутера.

### 3. `src/composables/useWebSocket.ts`
Инкапсулирует подключение к WebSocket бэкенда. Предоставляет реактивные свойства (`progress`, `status`, `matchedItems`, `totalItems`), управляющие состоянием полосы прогресса `MLProgressBar.vue`, с автоматической очисткой соединения в хуке `onUnmounted`.

## 🚀 Стек технологий
* **Ядро:** Vue 3 (`<script setup>`, Composition API), TypeScript, Vite
* **Стейт и маршрутизация:** Pinia, Vue Router
* **Стилизация и иконки:** Tailwind CSS v4 (`@theme`), `@lucide/vue`
* **Сетевой слой:** Axios, нативный WebSocket API

## 💻 Запуск проекта для разработки

1. **Установка зависимостей:**
   ```bash
   npm install
   ```
2. **Запуск dev-сервера (вместе с Vite Proxy на `http://localhost:8000`):**
   ```bash
   npm run dev
   ```
3. **Проверка типов и production-сборка:**
   ```bash
   npm run build
   ```
